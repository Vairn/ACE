ACE Showcase (host)

Windows 10+ x64. Run showcase.exe from this folder (data/ must sit beside the exe).
Or double-click run.bat.

This is the ACE example app on the host SDL chipset backend (OCS-style A500,
512K CHIP / 512K FAST). It is not an Amiga emulator.

Controls
  Arrows / WASD     menu and tests
  Return / Space    select, or fire
  Escape            back to menu
  F11               memory HUD
  F12               DMA / copper overlay
  F10               timing log (console)

Tests
  Blits, Input, Fonts, Copper, Blitter shapes, Blits with small dst,
  Interleaved bitmaps, Scroll buffer wrap, Shared buffer reuse, Twister,
  Simple buffer bpp fmode, Scroll tile buffer bpp fmode.

Needs SDL2.dll next to the exe (included). No install.
